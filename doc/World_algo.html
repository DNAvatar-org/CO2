📜 Ordre de Calcul & Interactions

  1. Rayonnement solaire → Entrée d'énergie
  2. Albédo global → Surface + nuages + glace
  3. Émission surface → σT⁴
  4. Absorption IR → CO₂, H₂O, CH₄ (HITRAN)
  5. Nuages → Réflexion + piégeage
  6. Convection → Profil T(z)
  7. Noyau → Flux géothermique
  8. Rétroactions → H₂O ↔ T°, Glace ↔ albédo

Interactions clés :

  • H₂O ↔ T° (Clausius-Clapeyron)
  • CO₂ ↔ Weathering (cycle long)
  • Glace ↔ Albédo (instabilité Snowball)
  • Nuages hauts → réchauffement / bas → refroidissement
