Démonstration des 6 patterns de traits

1. dash (tirets courts)
stroke-dasharray: 6,4
2. dot (points)
stroke-dasharray: 1,3
3. dashdot (tiret-point)
stroke-dasharray: 6,2,1,2
4. longdash (tirets longs)
stroke-dasharray: 10,4
5. longdashdot (tiret long-point)
stroke-dasharray: 10,2,1,2
6. solid (trait plein)
stroke-dasharray: none (pas de dasharray)

Correspondance avec les températures

7 températures × 6 patterns = patterns se répètent via modulo

  • 120K → dash (index 0)
  • 180K → dot (index 1)
  • 225K → dashdot (index 2)
  • 255K → longdash (index 3)
  • 275K → longdashdot (index 4)
  • 300K → solid (index 5)
  • 330K → dash (index 6, 6%6=0, donc même que 120K)
