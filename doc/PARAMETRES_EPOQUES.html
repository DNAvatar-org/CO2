Paramètres des Époques Géologiques - À Valider

Objectif : Définir les conditions initiales pour chaque époque géologique afin de permettre à l'utilisateur de "sauter" directement à une époque avec les bons paramètres.

Action requise : Valider cette liste de paramètres avant de rechercher les valeurs sur internet.

Paramètres à définir pour chaque époque

Paramètre Type Description Unité/Format Obligatoire
name string Nom de l'époque ex: "Hadéen", "Archéen" ✅ Oui
startYears number Début de l'époque (années avant maintenant) ex: 4.6e9 (4.6 milliards d'années) ✅ Oui
endYears number Fin de l'époque (années avant maintenant) ex: 4.0e9 ✅ Oui
emoji string Emoji représentant l'époque ex: "🌑", "🦠" ✅ Oui
co2_ppm number Concentration de CO₂ dans l'atmosphère ppm (parties par million) ✅ Oui
h2o_enabled boolean Vapeur d'eau activée (présence d'océans/atmosphère avec H₂O) true/false ✅ Oui
cloud_coverage number Couverture nuageuse moyenne 0 à 1 (0% à 100%) ⚠️ Optionnel (calculé si absent)
temperature_surface number Température de surface moyenne Kelvin (K) ou Celsius (°C) ⚠️ Optionnel (calculé si absent)
albedo number Albédo moyen de la planète 0 à 1 (0% à 100%) ⚠️ Optionnel (calculé si absent)
volcanoFactor number Facteur multiplicatif pour l'activité volcanique ex: 10.0 (10x plus actif) ⚠️ Optionnel (déjà dans GEOLOGICAL_ERAS)
co2PerVolcano number CO₂ émis par volcan (équivalent) ppm par volcan ⚠️ Optionnel (déjà dans GEOLOGICAL_ERAS)
description string Description textuelle de l'époque Texte libre ⚠️ Optionnel (pour documentation)

Note : Les paramètres marqués comme "Optionnel" peuvent être calculés automatiquement par le système si non fournis, mais il est préférable de les définir pour plus de précision historique.

Époques à définir

🌑 Hadéen (-4600 à -4000 Ma)

Paramètres à rechercher :

  • CO₂ atmosphérique (ppm)
  • Présence d'océans (H₂O activé ?)
  • Couverture nuageuse
  • Température de surface moyenne
  • Albédo (atmosphère dense, peu de réflexion ?)

🦠 Archéen (-4000 à -2500 Ma)

Paramètres à rechercher :

  • CO₂ atmosphérique (ppm)
  • Présence d'océans (H₂O activé ?)
  • Couverture nuageuse
  • Température de surface moyenne
  • Albédo

🌿 Protérozoïque (-2500 à -541 Ma)

Paramètres à rechercher :

  • CO₂ atmosphérique (ppm) - déclin progressif
  • Présence d'océans (H₂O activé ?)
  • Couverture nuageuse
  • Température de surface moyenne
  • Albédo (apparition de glaciations)

Note : Période très longue, peut nécessiter des sous-périodes (Cryogénien, etc.)

🦴 Paléozoïque (-541 à -252 Ma)

Paramètres à rechercher :

  • CO₂ atmosphérique (ppm)
  • Présence d'océans (H₂O activé ?)
  • Couverture nuageuse
  • Température de surface moyenne
  • Albédo

🦕 Mésozoïque (-252 à -66 Ma)

Paramètres à rechercher :

  • CO₂ atmosphérique (ppm) - élevé (2000-3000 ppm)
  • Présence d'océans (H₂O activé ?)
  • Couverture nuageuse
  • Température de surface moyenne (+6 à +8°C par rapport à aujourd'hui ?)
  • Albédo (peu de glaces)

Sous-périodes : Crétacé (-145 à -66 Ma) avec CO₂ très élevé

🦣 Cénozoïque (-66 Ma à aujourd'hui)

Paramètres à rechercher :

  • CO₂ atmosphérique (ppm) - 280 ppm avant industrie
  • Présence d'océans (H₂O activé ?)
  • Couverture nuageuse
  • Température de surface moyenne
  • Albédo (alternance glaces/interglaciaires)

Note : Période récente, données plus précises disponibles

Sources de données recommandées

  • CO₂ atmosphérique :
    • Modèles paléoclimatiques (GEOCARB, COPSE, etc.)
    • Proxies géochimiques (isotopes, fossiles)
    • Articles scientifiques sur l'évolution du CO₂
  • Température :
    • Reconstructions paléoclimatiques
    • Proxies de température (isotopes O¹⁸, fossiles)
    • Modèles climatiques rétrospectifs
  • Albédo et nuages :
    • Modèles climatiques paléoclimatiques
    • Estimations basées sur la couverture glaciaire
    • Comparaisons avec exoplanètes similaires

⚠️ Difficulté : Les données pour les époques très anciennes (Hadéen, Archéen) sont rares et souvent basées sur des modèles théoriques plutôt que des mesures directes. Il faudra probablement faire des approximations raisonnables.

Structure de données proposée

const EPOCH_INITIAL_CONDITIONS = [

    },
    // ... autres époques
