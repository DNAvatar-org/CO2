$$B_{\lambda}(T) = \frac{2hc^2}{\lambda^5} \frac{1}{e^{hc/(\lambda k_B T)} - 1}$$
$$F_{\text{solaire}} = S_0 \frac{1 - A}{4}$$
$$F = \sigma T^4$$
$$P(z) = P_0 e^{-z/H}$$
$$n_{\text{air}}(z) = \frac{P(z)}{k_B T(z)}$$
$$n_{\text{CO}_2}(z) = n_{\text{air}}(z) \times f_{\text{CO}_2}$$
$$\kappa = \sigma_{\text{CO}_2}(\lambda) \times n_{\text{CO}_2} + \sigma_{\text{H}_2\text{O}}(\lambda) \times n_{\text{H}_2\text{O}}$$
$$F_{\text{sortant}} = F_{\text{entrant}} - F_{\text{absorbé}} + F_{\text{émis}}$$
$$F_{\text{absorbé}} = \kappa \Delta z \times F_{\text{entrant}}$$
$$F_{\text{émis}} = \tau \times \pi B_{\lambda}(T) \Delta\lambda$$

$$T(z) = \begin{cases} T_0 + \Gamma z & \text{si } z < z_{\text{trop}} \\ T_{\text{trop}} & \text{si } z \geq z_{\text{trop}} \end{cases}$$
$$T_0 = \left(\frac{F_{\text{solaire}}}{\sigma}\right)^{1/4} + \Delta T_{\text{effet de serre}}$$

Définitions
\(\lambda\) = longueur d'onde (m)
\(B_{\lambda}(T)\) = fonction de Planck (W·m⁻²·m⁻¹·sr⁻¹)
\(z\) = altitude (m)
\(T(z)\) = Température (K)
\(T_{\text{trop}}\) = température à la tropopause (K)
\(P(z)\) = Pression (Pa)
\(n_{\text{air}}(z)\) = densité de l'air (m⁻³)
\(n_{\text{CO}_2}(z)\) = densité de CO₂ (m⁻³)
\(f_{\text{CO}_2}\) = fraction molaire de CO₂
\(S_0\) = constante solaire (W/m²)
\(A\) = albédo
\(F_{\text{solaire}}\) = flux solaire absorbé (W/m²)
\(\Delta F\) = forçage radiatif (W/m²)
\(\lambda\) = sensibilité climatique (K/(W/m²))
\(\Delta T\) = variation de température (K)
\(F_{\text{total}}\) = flux total (W/m²)
\(T_{\text{eff}}\) = température effective (K)
\(z_{\text{trop}}\) = hauteur de la tropopause (m)
\(r_{\text{H}_2\text{O}}(z)\) = ratio de mélange vapeur d'eau (fraction molaire)
\(F_{\text{H}_2\text{O}}\) = forçage radiatif H₂O (W/m²)
\(F_{\text{vapeur}}\) = forçage de la vapeur d'eau (W/m²)
\(F_{\text{nuages}}\) = forçage des nuages (W/m²)
\(\text{couverture}\) = couverture nuageuse (0 à 1)
\(f_{\text{CO}_2}\) = fraction molaire CO₂ (ppm = f × 10⁶)

Algorithmes & Convergence

Paramètres d'entrée (main.js)

plotData : Objet principal de données
  • lambda_range : Plage de longueurs d'onde (0.1 à 100 μm, pas 0.1 μm)
  • current : Résultats du calcul courant (flux, températures, albedo, etc.)
  • co2_ppm : Concentration CO₂ en ppm (parties par million)
CO2_STATES : États prédéfinis
  • 0 : 0 ppm (iceberg)
  • 1 : 280 ppm (pré-industriel, forêt)
  • 2 : 420 ppm (actuel, usine) - DÉFAUT
  • 3 : 560 ppm (×2, volcan)
  • 3+ : Multiplicateurs exponentiels (CO2_STATES[3] × 2^(state-3))
Options de simulation
  • z_max : Altitude maximale (défaut: 120000 m = 120 km)
  • delta_z : Pas d'altitude (défaut: 50 m)
  • lambda_min : Longueur d'onde min (défaut: 0.1×10⁻⁶ m)
  • lambda_max : Longueur d'onde max (défaut: 100×10⁻⁶ m)
  • delta_lambda : Pas de longueur d'onde (défaut: 0.1×10⁻⁶ m)

Phases de Convergence Récursive

Phase 1 : Initialisation
  • Calcul de T₀ initiale (approximation avec albedo de base)
  • Estimation du forçage CO₂ : ΔF = 5.35 × ln(CO₂/CO₂_ref)
  • Ajustement si H₂O activé : T₀ += 15K (approximation réduite)
  • Définition de l'intervalle de dichotomie : T₀ ± 50K
Phase 2 : Dichotomie (sous-phases)
  • 2.1 - Calcul initial : calculateFluxForT0(T₀_initial)
  • 2.2 - Affichage initial : displayDichotomyStep(iteration=0, isInitial=true)
  • 2.3 - Itération récursive :
    • Calcul du flux pour T₀_test
    • Comparaison : |flux_total - flux_solaire_absorbé| < tolérance (0.1 W/m²)
    • Si non convergé : ajustement T₀ (dichotomie classique)
    • Affichage progressif : displayDichotomyStep(iteration=i)
  • 2.4 - Convergence : Arrêt si |différence| < 0.1 W/m² ou max_iterations (20)
Phase 3 : Finalisation
  • Calcul des forçages radiatifs (CO₂, H₂O, Albedo)
  • Mise à jour de l'albedo dynamique (glace, nuages)
  • Mise à jour de la couverture nuageuse
  • Mise à jour de l'affichage (graphiques, visualisation spectrale)

Interactions & Rétroactions

H₂O ↔ T° (Rétroaction positive)
  • Température ↑ → Évaporation ↑ → Vapeur d'eau ↑ → Effet de serre ↑ → T° ↑
  • Modélisée via : waterVaporMixingRatio(z) = r₀ × exp(-z/H_H₂O)
  • Limite : T₀_initial += 15K (réduit pour éviter l'emballement)
Glace ↔ Albédo (Rétroaction positive)
  • Température ↓ → Glace ↑ → Albédo ↑ → Absorption solaire ↓ → T° ↓
  • Modélisée via : calculateAlbedo(T_surface, h2o_enabled)
  • Transition progressive : albedo_base → albedo_glace (~0.6-0.9)
Nuages (Effet complexe)
  • Réchauffement IR : Nuages → Absorption IR → Réémission vers le sol
  • Refroidissement albédo : Nuages → Réflexion solaire → Moins d'absorption
  • Modélisée via : calculateCloudCoverage(T_surface, h2o_enabled)
  • Effet net : dépend de la température et du type de nuages
CO₂ ↔ Weathering (Cycle long)
  • CO₂ ↑ → Température ↑ → Weathering ↑ → CO₂ ↓ (rétroaction négative)
  • Non modélisé dans cette version (cycle trop long pour la simulation)

Méthode de Convergence

Dichotomie (Bisection Method)

  1. Intervalle initial : [T₀_min, T₀_max] = [T₀_initial - 50K, T₀_initial + 50K]
  2. Test de convergence : |flux_total - flux_solaire_absorbé| < 0.1 W/m²
  3. Itération :
    • T₀_test = (T₀_min + T₀_max) / 2
    • Calculer flux_total pour T₀_test
    • Si flux_total > flux_solaire : T₀ trop élevée → T₀_max = T₀_test
    • Si flux_total < flux_solaire : T₀ trop basse → T₀_min = T₀_test
  4. Arrêt : Convergence atteinte OU max_iterations = 20

Équation d'équilibre : flux_total(T₀) = flux_solaire_absorbé(T₀)

Où flux_total inclut : émission IR, absorption CO₂/H₂O, rétroactions albedo/nuages
